# Laravel SMSLink Package & Notification Channel

> **Community Contribution Wanted!** 🚀

This directory is reserved for the official community-maintained **Laravel Package & Custom Notification Channel** for SMSLink.

## 🎯 Desired SDK Features
- Laravel Package with ServiceProvider & Facade (`SMSLink::send()`).
- Laravel Custom Notification Channel (`SMSLinkChannel`).
- Published config file (`config/smslink.php`).
- Auto-discovery for Laravel 8, 9, 10, 11+.

## 🤝 How to Contribute
1. Build your Laravel package inside this directory (`ecosystem/sdks/laravel-sdk/`).
2. Add package installation guide and `Notification` usage code examples.
3. Submit a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
