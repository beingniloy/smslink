# Node.js SDK (NPM Package)

> **Community Contribution Wanted!** 🚀

This directory is reserved for the official community-maintained **Node.js SDK** for SMSLink.

## 🎯 Desired SDK Features
- TypeScript & JavaScript client library (`npm install smslink-node`).
- Promise / async-await interface.
- Supports Express, NestJS, and standalone Node.js scripts.

## 🤝 How to Contribute
1. Build your Node.js package inside this directory (`ecosystem/sdks/nodejs-sdk/`).
2. Add `package.json`, TypeScript declarations, and usage examples.
3. Submit a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
