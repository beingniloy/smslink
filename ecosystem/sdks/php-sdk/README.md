# Native PHP SDK (Composer Package)

> **Community Contribution Wanted!** 🚀

This directory is reserved for the official community-maintained **PHP Client Library / SDK** for the SMSLink Gateway API.

## 🎯 Desired SDK Features
- Object-Oriented PHP Client (`SMSLink\Client`).
- PSR-4 autoloading compliant (`composer.json`).
- Outbound SMS dispatch method with SIM slot routing.
- Real-time status lookup and device polling.
- Unit tests using PHPUnit.

## 🤝 How to Contribute
1. Build the Composer package code inside this directory (`ecosystem/sdks/php-sdk/`).
2. Include a `composer.json` file and usage examples.
3. Submit a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
