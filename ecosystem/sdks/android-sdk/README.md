# Android Client SDK (Kotlin / Java Library)

> **Community Contribution Wanted!** 🚀

This directory is reserved for the official community-maintained **Android Client SDK** for SMSLink.

## 🎯 Desired SDK Features
- Kotlin / Java helper library for custom Android gateway apps.
- Dual-SIM TelephonyManager helper methods (`SubscriptionManager`).
- WebSocket / HTTP long-polling listeners.
- Device registration & CameraX QR Code payload parser.

## 🤝 How to Contribute
1. Build the Android library inside this directory (`ecosystem/sdks/android-sdk/`).
2. Include Gradle build configuration and usage instructions.
3. Submit a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
