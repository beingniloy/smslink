# Python SDK (PyPI Package)

> **Community Contribution Wanted!** 🚀

This directory is reserved for the official community-maintained **Python SDK** for SMSLink.

## 🎯 Desired SDK Features
- Async & Sync Python client (`pip install smslink-python`).
- Supports Django, Flask, FastAPI.
- Clean methods for sending SMS, checking status, and listing devices.

## 🤝 How to Contribute
1. Build the Python package inside this directory (`ecosystem/sdks/python-sdk/`).
2. Add `setup.py` / `pyproject.toml` and usage documentation.
3. Submit a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
