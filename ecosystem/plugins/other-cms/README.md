# Other CMS & E-Commerce SMS Extensions (OpenCart, Magento, PrestaShop, Filament)

> **Community Contribution Wanted!** 🚀

This directory is reserved for community-contributed extensions and plugins for other popular Content Management Systems (CMS) and E-Commerce platforms.

## 📦 Targeted Extensions
- **OpenCart SMS Extension** (`ecosystem/plugins/other-cms/opencart/`)
- **Magento 2 SMS Module** (`ecosystem/plugins/other-cms/magento/`)
- **PrestaShop SMS Module** (`ecosystem/plugins/other-cms/prestashop/`)
- **Laravel Filament SMS Plugin** (`ecosystem/plugins/other-cms/filament/`)

## 🤝 How to Contribute
1. Create a subfolder for your target CMS inside `ecosystem/plugins/other-cms/`.
2. Include full extension code, instructions, and configuration steps.
3. Submit a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
