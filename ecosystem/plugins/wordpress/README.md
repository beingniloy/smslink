# WordPress SMS Notification & OTP Plugin

> **Community Contribution Wanted!** 🚀

This directory is reserved for the official community-maintained **WordPress SMS & OTP Plugin** for SMSLink.

## 🎯 Desired Plugin Features
- Phone number verification & OTP login for WordPress users.
- New user registration SMS notifications.
- Password reset OTP via SMS.
- Admin settings panel in WordPress Dashboard to set Base URL and API Key.

## 🤝 How to Contribute
1. Build your WordPress plugin inside this directory (`ecosystem/plugins/wordpress/`).
2. Add a `readme.txt` (WordPress plugin format) and installation guide.
3. Open a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
