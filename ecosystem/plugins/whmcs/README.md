# WHMCS SMS Gateway Addon & Client Notification Module

> **Community Contribution Wanted!** 🚀

This directory is reserved for the official community-maintained **WHMCS SMS Gateway Module** for SMSLink.

## 🎯 Desired Module Features
- Custom Gateway Module for WHMCS (`modules/gateways/smslink.php` or `modules/addons/`).
- Automated Client Notifications (Invoice Created, Payment Received, Ticket Answered).
- Admin Order Alerts via SMS.
- Admin configuration UI for Base URL, API Key, and SIM Slot preference.

## 🤝 How to Contribute
1. Build your WHMCS module inside this directory (`ecosystem/plugins/whmcs/`).
2. Add installation steps and usage documentation.
3. Open a Pull Request to [beingniloy/smslink](https://github.com/beingniloy/smslink).
